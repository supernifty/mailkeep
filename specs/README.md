# Mailkeep specifications

Mailkeep uses specification-driven development. Every new feature must be specified in this directory before implementation begins.

Each feature specification should state:

- the problem or user need;
- the intended behavior and scope;
- relevant interfaces, data, and constraints;
- acceptance criteria; and
- explicit exclusions or unresolved questions.

Implementation should follow the specification. If the intended behavior changes during development, update the specification before changing the implementation.
